# 纽约市 Airbnb 数据分析项目

## 项目简介

本项目对 2019 年纽约市 Airbnb 开放数据进行深入的探索性数据分析和统计推断，揭示短租市场的关键特征和规律。

## 数据集

- **数据源**: [Kaggle - New York City Airbnb Open Data](https://www.kaggle.com/datasets/dgomonov/new-york-city-airbnb-open-data)
- **观测值**: 48,895 条房源记录
- **变量数**: 16 个特征变量
- **覆盖区域**: 纽约市五个行政区（Manhattan, Brooklyn, Queens, Bronx, Staten Island）

## 分析内容

### 第一部分：探索性数据分析 (EDA)

1. **数据集概览**
   - 数据结构和变量类型分析
   - 缺失值检查和数据质量评估

2. **描述性统计**
   - 价格、评论数、可用性等关键指标统计
   - 不同行政区和房间类型的对比分析

3. **可视化分析**
   - 行政区房源分布和价格对比
   - 房间类型价格分布
   - 价格与评论数关系分析
   - 地理分布热力图

### 第二部分：统计推断

#### 研究问题 1: 地理位置对价格的影响
- **假设检验**: Manhattan vs Brooklyn 价格比较（双样本 t 检验）
- **结论**: Manhattan 平均价格显著高于 Brooklyn
- **业务启示**: 地理位置是定价的关键因素

#### 研究问题 2: 房间类型对价格的影响
- **假设检验**: 整套房屋 vs 独立房间价格比较
- **结论**: 整套房屋价格显著高于独立房间（约 106% 差异）
- **业务启示**: 房间类型是重要的定价因素

#### 研究问题 3: 运营策略分析
- **假设检验**: 评论数量与可用天数相关性检验（Pearson 相关）
- **结论**: 存在弱正相关关系（r ≈ 0.16）
- **业务启示**: 成功运营需要多维度优化，不能仅依赖可用性

## 主要发现

- 📍 **地理溢价**: Manhattan 享有显著的位置溢价
- 🏠 **房型差异**: 整租比分租价格高出一倍以上
- 📊 **市场集中**: 75% 的房源集中在 Manhattan 和 Brooklyn
- 💡 **运营复杂性**: 房源成功需要价格、位置、服务等多因素协同
